
# COMP2245 Project 1

This is Project 1 for Renael Alfred.

## Project Description

Fresh Roots Market is a landing page created using HTML, CSS and JavaScript.

The project demonstrates CSS styling, Flexbox, CSS Grid, responsive web design and JavaScript form validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Features

- Responsive landing page
- Navigation menu
- Hero section
- Market feature cards
- Opening hours table
- Customer testimonial
- Mailing list form
- JavaScript form validation
- Success message after form submission

## Browser Testing

Browsers tested:
- Google Chrome
- Firefox
- Safari

## Images

The original illustrations and icons supplied with the Fresh Roots Market course starter repository were used.
